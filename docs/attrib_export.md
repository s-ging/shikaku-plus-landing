## 1. About Shikaku+ (verbatim app copy)

> Shikaku+ is a cooperative and competitive puzzle platform built on the
> Nikoli puzzle, Shikaku.
>
> The core mechanic is simple: partition a grid into rectangles so each
> rectangle contains exactly one number, and the rectangle's area matches
> that number.
